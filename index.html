What is NANDU AI?

NANDU AI is a personal AI assistant that I built to explore how local artificial intelligence, programming and memory can work together.

🤖 Personal AI

I built a Python-based conversational AI that communicates with a locally running Llama 3.2 model through Ollama.

🧠 Memory System

I created JSON files containing structured information so NANDU AI can receive public information about me.

💬 Conversation

The application keeps conversation messages so the model can understand the context of the current conversation.

🌐 Web Interface

I created this public website using HTML, CSS and JavaScript and deployed it with GitHub Pages.
