About NANDU

NANDU AI is a personal artificial intelligence assistant created as a learning project. It runs locally using Ollama and Llama 3.2, allowing the AI to interact without depending on a paid cloud AI service.

🕷️

Personal

Designed around one person instead of being a generic assistant.

🧠

Memory

NANDU can use stored information about its user when generating responses.

⚡

Local AI

The underlying AI model runs locally through Ollama.

NANDU Memory

NANDU is designed to remember useful information so conversations can become more personal over time.

The memory system stores structured information about preferences, interests, personality and goals. This information can then be included in the AI's context when responding.
