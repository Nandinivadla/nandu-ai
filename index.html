ABOUT NANDU

NANDU AI is a personal artificial intelligence project created to explore local Large Language Models, memory systems and intelligent assistants. Instead of being a generic chatbot, NANDU is being designed around one individual and their information.

◉

Personal

Built around the user's preferences, interests, goals and personality.

◇

Private

The current AI model runs locally through Ollama.

✦

Expandable

The architecture can evolve into a much more advanced AI agent.

PERSONAL MEMORY

NANDU can use structured memory to understand information about its user during conversations.

Memory can contain preferences, interests, habits, goals and other information that the user chooses to provide. This information is inserted into the AI's context when appropriate.
