What is NANDU AI?

NANDU AI is a personal AI assistant that I built from scratch to understand conversations, remember information about me, and respond using a locally running language model.

🧠 Personal Memory

NANDU AI uses structured JSON files to store information about my interests, personality, preferences and other non-private information.

🤖 Local AI

The project uses Ollama to communicate with a locally running Llama 3.2 model instead of depending completely on a cloud AI service.

💬 Conversation

The Python program maintains a conversation history and sends the conversation to the AI model so responses can remain connected to previous messages.

🌐 Public Interface

This website presents the project, explains how it works, and allows visitors to learn about me through public questions.

What I Built

01 — AI Assistant

I created a Python-based conversational AI application that accepts questions and generates responses using Llama 3.2 through Ollama.

02 — Memory System

I created JSON-based profile and memory files so the AI can receive structured information about me when generating responses.

03 — Conversation History

I implemented message history so the AI can maintain context during the current conversation.

04 — Web Interface

I created this website using HTML, CSS and JavaScript and deployed it using GitHub Pages.

The Memory

NANDU AI's memory is structured rather than being a random collection of text.

Profile

Basic public information such as my name, field of study, interests and goals.

Preferences

Music, weather, food, movies, nature, activities, aesthetics and other things I enjoy.

Personality

Public personality traits such as being more introverted, becoming talkative with people I am close to, and valuing love, respect and connection.

Boundaries

The public website does not expose private or sensitive personal information.

What I Learned

Python & AI Integration

I learned how a Python application can communicate with an AI model and process the model's response.

Local LLMs

I learned what a local large language model is and how Ollama can be used to run and communicate with models such as Llama 3.2 locally.

AI Memory

I learned that an AI does not automatically know personal information. Information has to be provided through prompts, conversation history or a memory system.

JSON Data

I learned how JSON can be used to organize structured information that Python can load and provide to an AI.

Virtual Environments

I learned how Python virtual environments isolate project dependencies and how packages such as the Ollama Python library can be installed inside the environment.

GitHub & Deployment

I learned how to upload a project to GitHub and deploy a frontend website through GitHub Pages.
